# wolvester-tech/.github

Org-wide default community health files for every repository under `wolvester-tech`.

- `PULL_REQUEST_TEMPLATE.md` – pre-filled PR body used by any repo that has no template of its own.
  PR title convention: `[DWT-n]: type(scope): English summary` (Jira project DWT).

GitHub requires this repository to be public, so keep it free of anything internal.
